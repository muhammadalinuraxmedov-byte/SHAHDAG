# SHAHDAG — MAP 01: RESIDENTIAL OPERATION

## Purpose
This milestone establishes the first playable residential operation footprint as a compact, believable tactical space.

## Geometry intent
- Compact street / sidewalk envelope instead of an open-world map.
- Two-storey target residence.
- Front yard, side access, rear yard and detached garage/storage area.
- Natural boundaries: fences, side-road blockers, closed perimeter and parked-car masses.
- Interior rooms are arranged to create multiple sightline choices and a connected ground-floor loop.
- Upper floor contains bedrooms/bathroom proxies and a stair landing suitable for later AI navigation and encounter design.

## Current implementation level
This is a code-generated **map foundation / greybox-plus** milestone. Primitive meshes establish scale, collision, room flow, lighting intent and cover locations. They are intentionally not presented as final AAA art.

## Final-art replacement plan
1. Replace primitive cubes with modular Nanite-compatible architecture.
2. Add authored trim sheets, PBR materials and decals.
3. Replace furniture proxies with final authored/procedural props.
4. Add glass, curtains, cables, outlets, switches, fixtures and small clutter.
5. Add final foliage/terrain/road dressing and believable neighboring buildings.
6. Add final lighting fixture models and tuned Lumen/Shadow settings.
7. Add sound zones, environmental ambience, rain and material-aware footsteps.
8. Add AI cover markers, navigation data and tactical spawn points.
9. Profile against the SHAHDAG Low / High / Epic performance budgets.

## Tactical route goals
- Front door is the obvious route, but not the only route.
- Side access provides a lateral approach.
- Rear door and garage create alternate entry/extraction choices.
- Interior partitions create short, readable CQB sightlines.
- Upper floor produces vertical pressure without becoming a large maze.
